# Foundational

| Architecture | Era | Summary |
|---|---|---|
| [Monte Carlo Methods](/received-canon/foundational/monte-carlo/) | 1940s | Computational algorithms that rely on repeated random sampling to approximate complex mathematical functions. |
| [Perceptron](/received-canon/foundational/perceptron/) | 1957–1969 | The original single-layer binary classifier; the atom of all neural networks. |
| [Multilayer Perceptron (MLP)](/received-canon/foundational/multilayer-perceptron/) | 1986 | Stacked layers with non-linear activations, trained via backpropagation. |
| [Backpropagation](/received-canon/foundational/backpropagation/) | 1986 | Chain-rule gradient flow that makes deep network training tractable. |
| [Hopfield Network](/received-canon/foundational/hopfield-network/) | 1982 | Recurrent energy-minimising memory; ancestor of modern associative memory. |
| [Bayesian Neural Network (BNN)](/received-canon/foundational/bayesian-neural-network/) | 1990s | Replaces deterministic weights with probability distributions to quantify uncertainty. |
