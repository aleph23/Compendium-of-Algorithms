# Convolutional Networks

| Architecture | Era | Summary |
|---|---|---|
| [Convolutional Neural Network (CNN)](/received-canon/convolutional/convolutional-neural-network/) | 1989–1998 | Exploits spatial locality via shared weight filters; backbone of computer vision. |
| [LeNet-5](/received-canon/convolutional/lenet/) | 1998 | LeCun's digit recogniser — the proof-of-concept that made CNNs credible. |
| [AlexNet](/received-canon/convolutional/alexnet/) | 2012 | GPU-powered deep CNN that ignited the modern deep-learning era at ImageNet 2012. |
| [ResNet (Residual Network)](/received-canon/convolutional/resnet/) | 2015 | Skip connections defeat vanishing gradients, enabling 100+ layer networks. |
