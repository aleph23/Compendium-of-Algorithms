# Generative Models

| Architecture | Era | Summary |
|---|---|---|
| [Variational Autoencoder (VAE)](/received-canon/generative/variational-autoencoder/) | 2013 | Probabilistic encoder–decoder learning a structured latent distribution. |
| [Generative Adversarial Network (GAN)](/received-canon/generative/generative-adversarial-network/) | 2014 | Generator vs Discriminator minimax game producing photorealistic samples. |
| [Diffusion Model (DDPM / Score Matching)](/received-canon/generative/diffusion-model/) | 2020–2022 | Iterative denoising of Gaussian noise learns to reverse a Markov diffusion chain. |
| [Flow Matching](/received-canon/generative/flow-matching/) | 2022–2023 | Continuous normalising flows trained by regressing straight-line probability paths. |
