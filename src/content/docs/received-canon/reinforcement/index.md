# Reinforcement Learning

| Architecture | Era | Summary |
|---|---|---|
| [Deep Q-Network (DQN)](/received-canon/reinforcement/deep-q-network/) | 2013–2015 | Q-value function approximated by CNN — Atari-playing breakthrough. |
| [Policy Gradient Methods (REINFORCE / PPO / A3C)](/received-canon/reinforcement/policy-gradient/) | 1992–2017 | Direct policy optimisation via stochastic gradient ascent on expected return. |
| [Reinforcement Learning from Human Feedback (RLHF)](/received-canon/reinforcement/rlhf/) | 2020–2023 | Human preference signal trains a reward model used to fine-tune LLMs via PPO. |
