# Recurrent Networks

| Architecture | Era | Summary |
|---|---|---|
| [Recurrent Neural Network (RNN)](/received-canon/recurrent/recurrent-neural-network/) | 1990 | Hidden state loops process arbitrary-length sequences, at the cost of vanishing gradients. |
| [Long Short-Term Memory (LSTM)](/received-canon/recurrent/lstm/) | 1997 | Gated cell state carries information across long sequences without gradient collapse. |
| [Gated Recurrent Unit (GRU)](/received-canon/recurrent/gru/) | 2014 | Streamlined LSTM — two gates instead of three, similar performance, lower compute. |
