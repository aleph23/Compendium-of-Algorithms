*These pages are assembled and updated biweekly by the Compendium Agent.*
*Old versions are archived, not deleted.*

Frontier contains architectures and techniques that have appeared in recent literature, preprint servers, or research announcements — but have not yet accumulated the citation weight, replication record, or community consensus required for admission to the Received Canon.

Some of what is here will prove foundational. Some will not. The Compendium makes no judgment in advance.

---

## Versioning

Frontier is semantically versioned by character-count mass:

| Threshold | Event |
|---|---|
| ±15% character-count change | Minor version increment |
| ≥15% content *reduction* | Minor increment + this version archived as a GitHub Release |
| ≥75% cumulative drift since last major | Major version increment |

The current version is displayed at the bottom of each Frontier page.
All archived versions remain permanently available as GitHub Releases.
