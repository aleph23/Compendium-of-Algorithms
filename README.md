# Compendium of Algorithms

> A living, auto-assembled reference covering every major neural-network architecture — from the 1957 Perceptron to whatever we invent tomorrow.

Each page is generated by an AI agent (Claude) and rebuilt biweekly via GitHub Actions into a fully-compiled Starlight static site.

---

## What each page contains

| Section | Contents |
|---|---|
| **Overview** | 3–5 paragraphs — problem, history, why it matters |
| **Architecture at a Glance** | Mermaid flowchart of all components |
| **Operational Flow** | Mermaid sequence/state diagram of one forward pass |
| **Layer Breakdown** | Every layer: purpose, I/O shapes, params, hyperparams |
| **Core Equations** | LaTeX math + symbol key table + plain-English paragraph |
| **Complexity Analysis** | Time, space, parameter count, FLOPs |
| **Strengths & Limitations** | Bullet lists |
| **Key Milestones** | Landmark papers chronologically |
| **See Also** | Cross-links to related architectures |

## Quick start (local)

```bash
# 1. Clone
git clone https://github.com/YOUR_USERNAME/ai-arch-book
cd ai-arch-book

# 2. Install Node deps
npm install

# 3. Install Python dep
pip install anthropic

# 4. Set your API key
export LLM_API_KEY=sk-ant-...

# 5. Generate all content (first run — takes ~10–20 min for full catalog)
python scripts/assemble_tome.py --all

# 6. Start dev server
npm run dev
```

## Adding a new architecture

1. Open `scripts/topics_registry.py`
2. Append a new dict to `TOPICS`:
   ```python
   {
       "id": "mamba",
       "title": "Mamba (Selective SSM)",
       "era": "2023",
       "category": "modern",
       "sidebar_order": 725,
       "depends_on": ["state-space-model"],
       "summary": "Hardware-aware selective scan makes SSMs competitive with Transformers.",
   },
   ```
3. Commit and push — the next biweekly run generates the page automatically.
   Or trigger the workflow manually with **mode = incremental**.

## GitHub Actions setup

### Required secret
| Secret name | Value |
|---|---|
| `LLM_API_KEY` | Your Anthropic API key (`sk-ant-...`) |

Set it at: **Settings → Secrets and variables → Actions → New repository secret**

### Workflow triggers
| Trigger | What runs |
|---|---|
| `schedule` (1st & 15th) | Incremental update — only new/changed topics |
| `workflow_dispatch` → *incremental* | Same as above, on demand |
| `workflow_dispatch` → *all* | Full regeneration of every page |

### Output branches
| Branch | Contents |
|---|---|
| `main` | Source scripts, topics registry, Astro config |
| `release-book` | Compiled static site (`index.html` + assets) |

---

## GitHub Pages deployment (optional)

1. Go to **Settings → Pages**
2. Set source to **Deploy from branch** → `release-book` → `/ (root)`
3. Uncomment the *Deploy to GitHub Pages* step in `.github/workflows/assemble.yml`
4. Set `ASTRO_BASE` in the workflow env to your repo name, e.g. `/ai-arch-book`
