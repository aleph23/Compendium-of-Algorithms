# Compendium of Algorithms

> A reference covering major neural-network architectures — from the Perceptron to tomorrow.

Each page is first generated by an AI agent, rebuilt biweekly via GitHub Actions into a fully-compiled Starlight static site, and proofed by real-flesh humans with squishy eyeballs. 👁

---

## What each chapter contains

| Section | Contents |
|---|---|
| **Overview** | 5 paragraphs — problem, history, why it matters |
| **Architecture** | Mermaid flowchart of all components |
| **Operational Flow** | Mermaid sequence/state diagram of one pass |
| **Layer Breakdown** | Model layers: purpose, I/O shapes, params, hyperparams |
| **Core Equations** | Pretty equation with symbol legend + plain-English paragraph |
| **Complexity Analysis** | Time, space, parameter count, FLOPs |
| **Strengths & Limitations** | Bullet lists |
| **Key Milestones** | Landmark papers chronologically |
| **Reference Material** | Documentation links and code examples |

## Architectures covered

See [`scripts/topics_registry.py`](scripts/topics_registry.py) for the full list.
Nearly 30 architectures across 8 generalities; add more with a PR.

Book One is fairly rigid, only getting edited by one of those smelly humans.
Book Two is the truly dynamic, AI-generated work.  Here we track SOTA and emergent tech.

---

### Adding a new architecture

1. Open `scripts/topics_registry.py`
2. Append a new dict to `TOPICS`:
   ```python
   {
       "id": "AGI ",
       "title": "Artificial General Intelligence",
       "era": "2031",
       "category": "modern",
       "sidebar_order": 825,
       "depends_on": ["state-space-model", "multimodal"],
       "summary": "Complex mixture of elements from prior work, acheiving repeatable general intelligence under standard training protocols.",
   },
   ```
3. Commit and push — the next biweekly run generates the page automatically.
   Or trigger the workflow manually with **mode = incremental**.
